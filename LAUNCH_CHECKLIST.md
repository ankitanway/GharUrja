# LAUNCH_CHECKLIST.md

## GharUrja Launch Checklist

This checklist is for the first public release of GharUrja.

The goal is to launch a clean, fast, trustworthy, lightweight solar site that can begin earning traffic, AdSense revenue, and qualified leads.

---

## Product Readiness

### Core Pages
- [ ] Home page is live
- [ ] Solar Size Calculator works
- [ ] Savings Calculator works
- [ ] Subsidy Estimator works
- [ ] Verified Installer listings page is live
- [ ] Quote Request form works
- [ ] About page is live
- [ ] Contact page is live

### Trust Pages
- [ ] Privacy Policy is published
- [ ] Terms page is published
- [ ] Disclaimer page is published
- [ ] Installer verification criteria page is published

### Content
- [ ] Bihar guide is published
- [ ] At least a few FAQ pages are live
- [ ] At least a few high-intent SEO pages are live
- [ ] Calculator pages include clear assumptions

---

## Technical Readiness

### Deployment
- [ ] Site deployed successfully
- [ ] Custom domain connected
- [ ] HTTPS is enabled
- [ ] Mobile layout tested
- [ ] Desktop layout tested
- [ ] Important pages load quickly

### Performance
- [ ] Pages are lightweight
- [ ] Images are optimized
- [ ] JavaScript is not excessive
- [ ] Core pages render fast on mobile

### Forms
- [ ] Quote request form submits cleanly
- [ ] Lead delivery flow is tested
- [ ] Lead forwarding reaches verified installers
- [ ] No unnecessary user data is stored

---

## SEO Readiness

- [ ] Page titles are unique
- [ ] Meta descriptions are present
- [ ] Headings are structured correctly
- [ ] Internal links are in place
- [ ] Sitemap is generated
- [ ] Robots.txt is configured
- [ ] Google Search Console is ready
- [ ] Bing Webmaster Tools is ready if desired

---

## Monetization Readiness

### AdSense
- [ ] Informational pages are ready for ad placement
- [ ] Site design does not look spammy
- [ ] Ad slots are planned carefully
- [ ] Content quality is strong enough for review

### Lead Monetization
- [ ] Verified installers are identified
- [ ] Installer contact process is defined
- [ ] Lead qualification rules are documented
- [ ] Manual fallback process exists in case automation fails

---

## Trust Readiness

- [ ] Subsidy data is editable
- [ ] Government source references are visible where needed
- [ ] Calculator assumptions are shown clearly
- [ ] Installer verification is manual or admin-approved
- [ ] Unverified vendors are excluded

---

## Analytics Readiness

Track only essential anonymous metrics:
- [ ] Page views
- [ ] Calculator completions
- [ ] Quote form submissions
- [ ] Installer clicks
- [ ] State page performance

Do not overbuild analytics.

---

## Operational Readiness

- [ ] Someone is responsible for updating subsidy information
- [ ] Someone is responsible for checking installer quality
- [ ] Someone is responsible for content updates
- [ ] Someone is responsible for lead follow-up

---

## Launch Content Minimum

Before launch, publish at least:
- [ ] 1 homepage
- [ ] 3 calculator-related pages
- [ ] 3 FAQ pages
- [ ] 1 state guide
- [ ] 3 installer profiles

---

## Post-Launch Checks

### First 48 Hours
- [ ] Check form submissions
- [ ] Check lead delivery
- [ ] Check page speed
- [ ] Check mobile usability
- [ ] Fix broken links
- [ ] Fix typos or unclear copy

### First 7 Days
- [ ] Review traffic sources
- [ ] Review calculator usage
- [ ] Review quote form conversion
- [ ] Review installer response quality
- [ ] Improve any weak pages

---

## Launch Criteria
Do not launch until:
- the calculators work,
- the content is useful,
- the installers are verified,
- the forms are reliable,
- and the site is fast and mobile-friendly.
